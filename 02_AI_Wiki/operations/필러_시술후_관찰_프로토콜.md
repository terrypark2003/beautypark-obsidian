# 필러·볼류마이징 시술 후 15분 관찰 프로토콜

> **2026-09-17 시행.** 필러 및 침습적 볼류마이징 시술 환자는 **시술 종료 후 원내 15분 대기**, 이상 없음을 확인한 뒤 귀가한다. **예외 없음.**
> ⚠️ `draft` — 관찰 항목의 의학적 내용은 **원장 검수 후** `verified`로 올린다.

## 1. 배경

환자 안전 프로토콜 세미나(2026-09-16) 참석 후 원내 안전 관리 시스템을 보강한다.

필러의 드문 중대 합병증은 **시술 직후 수 분 내에 징후가 나타나는 경우**가 있고, **발견이 빠를수록 처치가 쉽다.** 15분 관찰은 그 시간을 제도적으로 확보하기 위한 것이다.

관찰을 "했다"는 **기록이 남는 것** 자체도 이 절차의 목적이다.

## 2. 적용 대상

| 구분 | 시술 |
|---|---|
| **명확히 포함** | 필러 전 제품(벨로테로·레스틸렌·리쥬비엘 등), 볼류마이징 목적 주입 시술 |
| **⚠️ 경계 — 확정 필요** | 스킨부스터(리쥬란·쥬베룩·리투오·쥬브아셀·물광주사 등). 볼류마이징은 아니나 **침습적 주입**이다 |
| **제외** | 보톡스·스킨보톡스(볼류마이징 아님), 비침습 레이저·관리 |

> ⚠️ **원장이 대상 시술 목록을 확정해야 한다.** 경계가 모호하면 현장에서 매번 판단하게 되고 절차가 무너진다. 스킨부스터를 포함하면 안전은 올라가나 회전율이 떨어지므로 원장 결정이 필요하다.

## 3. 절차

```
시술 종료
   ↓ 종료 시각 기록 (어시팀)
15분 원내 대기 — 관찰 (어시팀)
   ↓
이상 없음 확인 → 확인자 기록 → 귀가 안내
이상 징후 → 즉시 원장 호출 (지켜보지 않는다)
```

## 4. 관찰 항목

시술 부위와 전신을 함께 본다.

| 계통 | 징후 |
|---|---|
| 혈류 이상 | 시술 부위 **창백**(하얗게 질림), **얼룩덜룩한 그물 모양 색 변화** |
| 통증 | 시술 통증을 **넘어서는 심한 통증** |
| 시각 | **눈 통증, 시야 흐림·시력 저하** |
| 혈관미주신경 | 어지럼, 식은땀, 메스꺼움, 창백 |
| 과민반응 | 두드러기, 입술·혀 부종, 호흡 곤란 |

**시각 증상은 즉시 보고한다.** 미간·코·이마 등 부위 시술에서 특히 주의한다.

> ⚠️ 위 항목은 일반 임상 지식과 세미나 내용을 정리한 것이다. **원장 검수와 문헌 근거 보강이 필요하다**(CLAUDE.md §3 출처 병기 의무). 보강 후 [[팩트체크_로그]]에 등재한다.

## 5. 이상 징후 시

1. **즉시 원장을 호출한다.** "조금 지켜보자"는 하지 않는다
2. 환자를 귀가시키지 않는다
3. 발생 시각과 증상을 기록한다

## 6. 기록

| 항목 | 내용 |
|---|---|
| 시술 종료 시각 | 관찰 시작점 |
| 관찰 종료 시각 | 15분 경과 확인 |
| 확인자 | 귀가 안내한 직원 이름 |
| 특이사항 | 증상 발생 시 시각·내용·조치 |

기록 위치(차트 / 별도 대장)는 확정이 필요하다.

## 7. 팀별 역할

| 팀 | 역할 |
|---|---|
| **상담** | 시술 **전** 상담에서 15분 대기를 미리 안내. 고객이 일정을 잡을 때 반영되게 한다 |
| **데스크** | 예약 시 시술 시간 + 15분 확보. 시술 후 대기 자리 안내. 귀가 전 어시팀 확인 완료 여부 확인 |
| **어시** | 종료 시각 기록 → 15분 관찰 → 이상 시 원장 호출 → 이상 없으면 기록 후 귀가 안내 |

**상담 단계 안내가 가장 중요하다.** 시술이 끝난 뒤에 처음 들으면 고객은 "왜 못 가게 하냐"가 된다. 미리 알면 "챙겨준다"가 된다. → [[데스크_응대기준]]
