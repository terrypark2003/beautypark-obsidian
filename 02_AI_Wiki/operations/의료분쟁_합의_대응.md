# 의료분쟁 합의·소송 판단 기준

> 시술 후 분쟁이 배상 청구로 넘어갔을 때 **합의할지 다툴지**를 판단하는 절차.
> **환자 식별정보·진료 내용·보험사명은 이 노트에 쓰지 않는다.** 판단 구조만 남긴다.
> ⚠️ draft — 실제 적용은 의료전문 변호사 검토를 전제로 한다.

## 1. 원내 보험 조건 (2026-09 확인)

| 항목 | 내용 |
|---|---|
| 자기부담 구조 | **면책금 500만원 + 초과분의 10%** (손해분담 약관) |
| 약관 변경 | **불가** — 정확한 확인은 모집대리점 |
| 소송 방어비용 | **보험사 부담** (위임받아 진행 시) |
| 변호사 대리 범위 | **민사소송 단계만.** 환자 응대·이메일 단계는 불가 |
| 보험료 할증 | §2 구간표 |

```
병원 부담 = 500만원 + (배상액 − 500만원) × 10%
```

## 2. 보험료 할증 구간

| 지급 규모 | 할증률 |
|---|---:|
| 500만원 미만 | 15% |
| 500만~1,000만원 | 30% |
| **1,000만~3,000만원** | **50%** |
| 3,000만~5,000만원 | 70% |

> ⚠️ **미확인 2건** — 할증 기준이 **손해액**인지 **보험사 지급액**인지, 그리고 **적용 기간**(몇 년). 지급액 기준이면 같은 사건도 구간이 한 칸 내려갈 수 있다.

## 3. 표로 세우고 시작한다

| 시나리오 | 배상액 | 병원 부담 | 할증 | 기간 |
|---|---:|---:|---:|---|
| 합의 | 제시액 | §1 계산식 | §2 | 즉시 |
| 소송 패소 | 손해사정사 예상액 | §1 계산식 | §2 | 1~2년 |
| 소송 승소 | 0원 | **0원** | **없음** | 1~2년 |

### 여기서 나오는 세 가지

**① 합의금 협상은 병원의 이익이 아니다**

배상액을 500만원 깎아도 병원은 **50만원**만 덜 낸다. 깎인 금액의 90%는 보험사 몫이다.
→ **금액 협상에 시간을 쓰지 않는다.** 병원이 챙길 것은 조건이다(§5).

**② 배상액이 0이면 병원 부담도 0이다**

보험금 지급이 없으면 면책금도, 할증도 발생하지 않는다.

**③ 소송 예상액이 합의안보다 낮으면 합의가 가장 비싸다**

> 2026-09 사례: 합의 제안 2,500만원(병원 700만원) vs 소송 예상 1,500만원(병원 600만원).
> **지더라도 합의보다 쌌다.** 방어비용이 보험사 부담이라 소송 쪽 추가 비용도 없었다.
> 할증은 두 경우 모두 같은 구간(1,000만~3,000만)이라 **비교에서 상쇄**됐다.

**이 계산을 하지 않으면 자동으로 합의로 기운다.**

## 4. ⚠️ 합의서에 「과실 없음」은 넣을 수 없다

가장 중요한 제약이다. 2026-09에 확인됐다.

> 보험 약관상 **피보험자의 의료행위상 과실에 기인한 사고**에 대해 보험사가 법률상 손해배상금으로 보험금을 지급한다. 따라서 **합의금을 보험으로 받는다는 것은 일정 부분 과실이 존재한다는 전제**가 되고, 합의서에 과실이 아니라는 내용을 기재하기 어렵다.

### 구조적 딜레마

손해사정사가 **"법률상 배상책임이 없는 사고로 추정"**한다고 하면서도 보험금 지급을 전제로 합의를 제안하는 일이 생긴다. **두 진술은 양립하지 않는다.**

| | |
|---|---|
| 보험금을 받는다 | → 과실 인정 구조에 들어간다 |
| 과실 없음을 문서로 남긴다 | → 보험금을 못 받는다 |

**→ 합의의 진짜 비용은 자기부담금이 아니라 「과실이 있었다」는 기록이다.**
반대로 **소송에서 이기면 「책임 없음」 판결문이 남는다.** 합의서로는 얻을 수 없는 것이다.

### 대안 — 과실을 언급하지 않는 우회 문구

```
· 당사자는 본 합의의 내용 및 합의금 지급 사실을
  다른 분쟁·절차에서 원용하지 아니한다.
· 본 합의는 분쟁의 신속한 종결을 위한 것이다.
```

과실을 인정하지도 부인하지도 않아 약관과 충돌하지 않는다. **실제 효력은 변호사 확인 필요.**

## 5. 합의서 필수 조항

| 조항 | 없으면 |
|---|---|
| **일체의 청구권 포기 + 부제소 합의** | 돈을 주고도 다시 청구받는다 |
| **제3자 명의 청구 차단** | 가족 명의로 재청구된다 |
| **비밀유지** | 온라인에 올라가면 합의금이 무의미해진다 |
| 원용 금지 (§4) | 향후 유사 건의 선례가 된다 |
| ~~책임 부인 명시~~ | **불가 — §4 참조** |

**합의서 최종본은 의료전문 변호사 검토를 받는다.** 손해사정사는 보험사 쪽 이해관계를 함께 본다. 조항 하나 누락되는 비용이 자문료보다 크다.

## 6. 결정 전 확인 목록

| 항목 | 2026-09 결과 |
|---|---|
| 소송 방어비용 부담 주체 | ✅ **보험사 부담** (민사소송 단계) |
| 환자 응대 단계 변호사 | ✅ **불가** — 소송 전에는 병원이 직접 |
| 소송 시 예상 배상액 | ✅ 받음 |
| 보험료 할증 구간 | ✅ 받음 |
| 할증 기준·기간 | ❌ 미확인 |
| 「배상책임 없음」 판단의 서면화 | 요청함 |

> **할증 규모를 확인하기 전에 수락하지 않는다.** 연 할증액 × 적용 연수가 자기부담금에 더해진다.

## 7. 숫자로 안 잡히는 비용

2026-09 사례는 **소송이 더 쌌는데도 합의로 종결**했다. 근거는 금액이 아니었다.

> 손해사정사 의견: 환자 성향상 **병원과 장기적으로 상당한 악감정이 남을 것으로 우려**되어 지급 후 종결을 권고.

합의를 택할 정당한 이유는 있다. 다만 **그것이 이유라는 걸 알고 택하는 것**과 계산을 안 해보고 택하는 것은 다르다.

| 숫자에 안 잡히는 항목 |
|---|
| 1~2년간 진료 집중도 저하 |
| 직원 응대 부담 |
| 온라인 확산 위험 |
| 환자와의 장기 갈등 |

## 8. 정황 읽기

| 관찰 | 해석 |
|---|---|
| 환자가 **외부 의료심사를 거부** | 객관적 판정이 불리할 수 있다고 본다는 신호 |
| 청구액이 크게 내려감 (4,600만 → 2,500만) | 근거가 약하다는 신호. 다만 **더 깎는 실익은 §3① 참조** |
| 손해사정사가 "대화가 원활하지 않다" | 합의해도 조용할 보장이 없다. 비밀유지 조항이 더 중요해진다 |
| 보험사가 **선제적 소송**을 제안 | 보험사 부담이 크게 줄어드는 방향. **병원과 이해가 일치하는 경우가 많다** |

## 9. 응대 원칙

- **자백성 표현을 쓰지 않는다.** 대외 문서는 손해사정사·변호사 검토를 거친다 → [[CP_대응_시술후_불만]]
- **협상은 보험사로 넘긴다.** 자료 제공에는 성실히 협조하되, 배상 범위·금액 협상은 보험사를 통한다. 2026-09 사례에서 처음부터 이 스탠스를 문서로 밝혀 유지했다
- **확답을 먼저 주지 않는다.** "원칙적으로 수용 가능한 방향" 정도로 열어두고 확인 사항을 받은 뒤 확정한다
- **조건을 먼저 걸고 초안을 요구한다.** 합의서를 받은 뒤 조항 추가를 요청하면 협상이 한 바퀴 더 돈다
