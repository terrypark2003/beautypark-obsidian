# 피부팀 서비스 기준

> 2026년 6월 월간 회의 피드백으로 공지된 기준. **원본이 카톡 공지에만 있어 위키로 옮겼다.**
> 잔여물 항목은 절차가 별도로 확정되어 [[시술_마무리_확인절차]]로 분리했다.

## 0. 3개월 점검 결과 (2026-09-10)

6월 공지 후 3개월간 실제로 개선 여부가 확인되는 항목은 **6개 중 2개**뿐이다.

| 항목 | 3개월간 남은 근거 | 판정 |
|---|---|---|
| A-1 얼굴 잔여물 | 이마·헤어라인 사례, 얼굴 전면 사례(데스크 발견), 실장 반복 지적 | **미개선** |
| A-2 터번·가운·베드 | 없음 | 확인 불가 |
| B-1 동선 안내 | 없음 | 확인 불가 |
| C-1 설명 3단계 | 없음 | 확인 불가 |
| C-2 시술 매뉴얼 통합 | 저장소·위키에 시술 설명 자료 0건 | **미완료** |
| D-1 온도 사전 고지 | 없음. 9월 CX 워크시트에 담요·체감온도 재등장 | 확인 불가 |

**구조적 원인**: 6월 공지에는 체크리스트만 있고 **누가 언제 확인하는지가 없었다.** 잔여물만 드러난 것은 데스크·실장 눈에 우연히 띄었기 때문이지 나머지가 지켜지고 있다는 뜻이 아니다. 기준을 만들 때는 **확인 주체와 주기를 함께 정한다.**

## A. 마감 · 청결 · 위생

### A-1. 얼굴 잔여물 → [[시술_마무리_확인절차]]

6월 체크리스트(아래 4항목)는 유효하며, 2026-09-10부터 거울 확인 절차와 페널티가 추가됐다.

- [ ] 눈썹 **모 결 따라** 닦았는지
- [ ] 입술 라인 **물기 묻혀** 재확인했는지
- [ ] 헤어라인 따라 닦았는지
- [ ] 잔여물 재확인했는지

**입술은 마르면 제거가 어렵다.** 웻거즈로도 쉽게 지워지지 않으므로 물기를 묻혀 부드럽게 제거한 뒤 재확인한다.
자주 남는 부위: **입술 · 눈썹(모 안쪽) · 헤어라인**.

### A-2. 터번 · 가운 · 베드 세팅

**기준 — 고객이 입실했을 때 "지금 바로 누워도 되는 상태"가 기본 세팅이다.**

- [ ] 베드 시트 팽팽하게 정돈
- [ ] 터번·가운 깨끗한 상태로 교체
- [ ] 카트 위 정리 완료
- [ ] 사용 제품 외 노출 최소화
- [ ] 바닥·베드 주변 정돈

고객 체감 포인트: 터번 오염, 가운 얼룩, 베드 주변 정리 미흡, 입실 시 세팅 미완성.
**마무리 후 즉시 정리**를 루틴으로 한다.

## B. 대기 · 동선 · 시간

### B-1. 시술 후 동선 안내

**기본 원칙 — 방향 지시가 아니라 자리까지 안내한다.**

- [ ] 고객을 **바라보고** 직접 안내했는지
- [ ] 다음 위치까지 **동행**했는지
- [ ] "여기 앉아 계시면 됩니다" 명확히 안내했는지

"저쪽으로 가세요" 식 방향 안내로 끝내지 않는다. 관리 후 다음 시술이 연결되는 경우 **시술실 앞 대기 의자까지 직접 안내**한다.

## C. 커뮤니케이션 · 설명

### C-1. 오늘 무엇을 했는지 설명 (3단계)

고객이 "오늘 뭐 했지?"라고 느끼지 않도록 **30~40초 이상** 설명한다.

| 단계 | 내용 |
|---|---|
| ① | 오늘 한 **시술 이름** |
| ② | **작용 원리** 한 문장 |
| ③ | 오늘 **기대 효과** |

예시 — "오늘은 LDM으로 진정과 장벽 회복을 도와드렸고, 수분 밀도를 높이는 관리라 당일에는 촉촉함, 며칠 동안은 붉음 진정이 기대됩니다."

### C-2. 주의사항 · 당일 관리 설명 표준화 ⚠️ 미완료

**계획**: 시술별 매뉴얼 통합 정리 → 병원 전체 단일 멘트 / 시술 후 안내 표준화 / 신규 직원 교육 자료화
**요청**: 팀장이 현재 사용 중인 시술 설명 자료를 전부 수합해 전달

> ⚠️ **2026-09-10 확인 결과 수합 자료가 들어오지 않았다.** 저장소 `01_Raw_Data/_INBOX/`가 비어 있고 [[시술_핵심지식]]·[[진료_프로토콜]]이 `seed` 상태 그대로다. 자료가 들어와야 통합 매뉴얼 작업을 시작할 수 있다.

## D. 통증 · 온도 · 프라이버시

### D-1. 온도 사전 고지

**기본 원칙 — 불편을 참게 하지 않는다. 먼저 안내하고 선택권을 드린다.**

- [ ] "침대가 조금 따뜻할 수 있어요."
- [ ] "너무 덥거나 불편하시면 바로 말씀 주세요."
- [ ] 자극감 사전 고지

발생 유형: 침대 과열, 쿨링 온도 설명 부족, **고객이 참다가 나중에 말함**.
체감 온도는 개인차가 크다 → [[데스크_응대기준]] 6번(담요 사전 준비)과 같은 문제다.

## 점검 방법 (제안)

각 항목은 1주 관찰이면 판정이 가능하다.

| 항목 | 확인 방법 | 표본 |
|---|---|---|
| A-1 잔여물 | 데스크 퇴원 시 2차 확인 건수 집계 | 상시 |
| A-2 세팅 | 실장이 입실 직전 베드를 하루 3개 무작위 확인 | 1주 21개 |
| B-1 동선 | 시술 후 인계 장면 관찰 (방향 지시 / 자리까지 동행) | 1주 |
| C-1 설명 | 데스크가 수납 시 "오늘 어떤 관리 받으셨는지 설명 들으셨어요?" — **고객 입에서 시술명이 나오면 통과** | 1주 |
| D-1 온도 | 시술 전 멘트 관찰 또는 C-1과 같은 방식으로 확인 | 1주 |
