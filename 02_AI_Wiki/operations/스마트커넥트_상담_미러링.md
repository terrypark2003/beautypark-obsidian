# Smart Connect — 상담 화면 태블릿 미러링

> PC 화면을 태블릿에 그대로 띄워 환자에게 보여주는 기능. 2026-09-16 업데이트로 사용 가능.
> **[[토닝_상담_동선]]의 "원장이 보면서 설명한다" 단계를 실제로 구현하는 도구다.**

## 1. 사용 방법

1. 우측 상태 표시줄의 **Smart Connect** 아이콘을 **더블 클릭**
2. 왼쪽 상단에서 **연결된 태블릿** 선택
3. **교차 제어** 클릭
4. 디스플레이 옵션에서 **PC 디스플레이 미러링** 선택
5. **교차 제어 시작**

이 상태에서 PC 화면이 태블릿에 그대로 나온다.

## 2. 활용

| 용도 | 내용 |
|---|---|
| 상담 자료 제시 | 시술 설명 자료를 환자와 같은 화면으로 보며 설명 |
| **야누스 분석 제시** | 피부 진단기 촬영 직후 분석 결과를 환자에게 직접 보여주며 설명 |

야누스 활용이 핵심이다. [[토닝_상담_동선]] ③단계에서 원장이 판독 결과를 **말로만 전달하는 것과 화면으로 같이 보는 것은 설득력이 다르다.** 환자가 자기 피부 상태를 숫자와 이미지로 확인한 뒤 상담에 들어간다.

## 3. ⚠️ 시작 전 화면 정리 — 필수

**미러링은 PC 화면 전체를 그대로 내보낸다.** 다른 환자 정보가 떠 있으면 그대로 노출된다.

교차 제어를 시작하기 **전에** 반드시 확인한다.

- [ ] **예약판을 닫는다** — 다른 환자 성함·연락처·시술 내역이 한 화면에 있다
- [ ] **다른 환자 차트·스마트CRM 창을 닫는다**
- [ ] 보여줄 자료만 띄운 상태로 만든다
- [ ] 메신저·단톡 알림 팝업을 끈다 (직원 간 대화가 뜰 수 있다)
- [ ] **상담이 끝나면 즉시 교차 제어를 해제한다**

다른 환자의 진료 정보가 노출되면 개인정보 보호법상 안전조치 의무 위반이자 의료법 제19조 비밀 누설 문제가 된다. **한 번의 실수가 분쟁이 된다.**

## 4. 야누스 사진을 다룰 때

- 야누스 촬영 이미지는 **민감정보**(건강에 관한 정보)다
- 태블릿에 띄운 화면을 환자가 **촬영하는 것은 본인 정보이므로 제한하지 않는다**
- 다른 환자의 전후 비교 사진을 상담에 쓰려면 **그 환자의 동의**가 있어야 한다 → [[시술사진_초상사용_계약]]
- 외부(인스타그램·홈페이지) 사용은 별도 계약 영역이다

## 5. 후속

- [ ] 태블릿을 환자에게 직접 건네는지, 직원이 들고 보여주는지 운영 방식 확정
- [ ] 태블릿 화면 잠금·자동 잠금 시간 설정 확인
- [ ] 상담실별 태블릿 대수와 배치
- [ ] 화면 정리 체크를 [[운영_SOP]] 상담 준비 절차에 반영
- [ ] 실장·코디팀 대상 시연 교육 일정
