# 파트타임 진료의 근무 운영

> 주 단위 근무일수가 변동되는 파트타임 진료의의 스케줄 확정·공휴일 처리 절차.
> **개인 식별정보는 기록하지 않는다.** 인명·연락처·급여는 이 노트에 쓰지 않는다.

## 1. 스케줄 확정 절차

1. 전월에 **다음 달 가능 요일**을 본인에게 확인받는다
2. 해당 요일의 날짜를 모두 뽑아 **근무일 목록**을 만든다
3. **공휴일과 겹치는 날**을 확인해 휴진일로 분리한다
4. 휴진분에 대해 **대체근무를 요청**한다
5. 본인이 대체 날짜를 회신하면 **최종 스케줄을 다시 안내**한다

## 2. 스케줄 안내 문안 구조

세 덩어리로 나눈다. 섞으면 받는 사람이 어느 날 나와야 하는지 헷갈린다.

| 구역 | 내용 |
|---|---|
| **근무일** | 실제 출근하는 날만. 휴진일을 여기 넣지 않는다 |
| **휴진일** | 공휴일명과 함께 별도 표기 |
| **대체근무 요청** | 사유를 합산해 **요청 일수만** 제시하고 날짜는 본인이 고르게 한다 |

**대체근무는 사유별로 나누지 말고 합쳐서 일수로 던진다.** 사유마다 ①②로 나누면 상대가 날짜 계산을 하게 되고 회신이 늦어진다. "휴진분과 단축진료분을 합쳐 2일"로 결론만 주는 편이 빠르다.

## 3. 2026년 10월 사례

| 항목 | 내용 |
|---|---|
| 본인 가능 요일 | 월·목·금·토 |
| 해당 날짜 | 19일 |
| 공휴일 겹침 | 3일(토) 개천절, 5일(월) 대체공휴일, 9일(금) 한글날 |
| 처리 | 3일·9일 휴진, 5일 단축진료 |
| 확정 근무일 | 17일 |
| 대체근무 요청 | 2일 (6~28일 중 본인 선택) |

2026년 10월 3일 개천절이 토요일과 겹쳐 **5일(월)이 대체공휴일**이 됐다. 공휴일이 토·일과 겹치면 대체공휴일이 생기므로 스케줄을 짤 때 달력만 보지 말고 **대체공휴일까지 확인**한다.

## 4. ⚠️ 미해결 — 노무법인 회신 대기

2026-09-17 노무법인에 연차 산정을 문의했다. **아래는 답이 오기 전까지 확정하지 않는다.**

### 문의한 것

- 근무일수가 주 2일 → 주 3~4일 → 주 4일로 변동될 때 연차 산정 방법
- 입사일부터 현재까지 월별 연차 발생·잔여 일수 표
- 향후 근무일수 변동 시 원내에서 직접 계산할 기준

### 아직 묻지 않았고 확인이 필요한 것

| 쟁점 | 왜 필요한가 |
|---|---|
| 공휴일 휴진일이 **유급휴일**에 해당하는지 | 소정근로일과 겹친 공휴일의 임금 처리가 달라진다 |
| 휴진일을 **연차로 차감**할 수 있는지 | 병원 사정으로 쉰 날을 근로자 연차에서 빼는 구조가 된다 |
| **대체근무 요청의 적법성**과 필요 절차 | 휴일대체는 절차 요건이 있을 수 있다 |
| **단축근무일**의 임금·연차 처리 | 대체공휴일에 단축진료하는 날이 있다 |

> ⚠️ **"연차로 대체 가능하다"고 먼저 안내하지 않는다.** 답을 받기 전에 안내하면 번복해야 한다. 여지를 남길 때는 "처리 방법은 확인해서 다시 안내드리겠다"로 쓴다.
