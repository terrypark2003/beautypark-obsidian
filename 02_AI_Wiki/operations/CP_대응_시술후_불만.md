# CP 대응 — 시술 후 불만

> 시술 후 상태 악화를 호소하는 환자 응대 기준과 의무기록 작성법.
> **개인 식별정보는 기록하지 않는다.** 환자명·차트번호·연락처는 이 노트에 쓰지 않는다.

## 1. 대응 원칙 다섯

| 원칙 | 내용 |
|---|---|
| **"아니다"로 시작하지 않는다** | 인과를 먼저 부정하면 환자는 방어로 받아들이고 그때부터 설득이 안 된다. **기전을 설명하고 환자가 스스로 납득하게** 한다 |
| **시술의 한계를 말한다** | "그 시술은 원인이 아니다"보다 **"그 시술로 이것까지는 개선되지 않는다"**가 방어력이 높고 사실에도 부합한다 |
| **원내 다른 시술을 원인 후보로 올리지 않는다** | 인과를 벗어나려고 다른 시술을 끌어오면 **병원 안에서 원인을 옮기는 꼴**이 된다. 내부 판단 근거로만 둔다 |
| **보상·환불·무상 재시술을 즉석에서 말하지 않는다** | 인과를 인정한 것으로 해석될 수 있다 → [[환불_규정]] |
| **다음 시술의 한계를 미리 설명하고 기록한다** | 제안한 시술로 또 불만이 나올 수 있다. "일시적"이라고 설명하고 이해를 확인한 기록이 그때의 근거가 된다 |

## 2. 의무기록 작성 구조

**환자 진술 · 의학적 판단 · 설명 내용을 분리해 적는다.**

| 항목 | 쓰는 법 |
|---|---|
| 환자 호소 | "**~라고 호소함 / 진술함**" — 환자 주장을 그대로 남기되 병원이 인과를 인정한 것이 되지 않는다 |
| 경과 | 날짜별 시술·관찰 이력 (사실만) |
| 진찰 소견 | 실제 관찰한 것 |
| 설명 내용 | "**~임을 설명함**" — 설명한 사실의 기록 |
| 제안 및 동의 | 제안 내용 + **한계 설명** + "환자분께서 이해하신 것으로 확인함" |
| 환자 반응 | 환자 답변 |

> ⚠️ 진료기록부는 사실을 그대로 적는 문서다(의료법 §22). **인과를 단정해 쓰지 않고**, 설명한 내용과 판단 근거를 적는다. 허위 기재는 금지된다.

**함께 확보할 것** — 원 시술의 주입 부위·용량 기록, 시술 전 사진, 금일 야누스 촬영본. **CP는 기록의 완결성이 전부다.** → [[스마트커넥트_상담_미러링]]

## 3. 사례 — 스킨부스터 시술 후 좌우 비대칭 호소 (2026-09)

### 경위

5월 말 리투오 시술 → 7월 경과 관찰 및 다른 시술 시행 → 9월 재내원. **우측 심부볼, 좌측 팔자주름**이 시술 후 깊어졌다고 호소.

### 인과 가능성이 낮다고 본 근거

| 근거 | 내용 |
|---|---|
| **기전** | 리투오는 hADM 기반 ECM 부스터(콜라겐 89% · 엘라스틴 3% · GAG 0.4% 등)로 진피에 성분을 **보충**한다. 조직 위축·볼륨 감소를 유발하는 기전이 아니다. 이상반응이 생긴다면 결절·염증처럼 **더해지는 쪽**이다 |
| **좌우 패턴** | 시술은 양측 대칭으로 진행하는데 호소 부위는 **서로 다른 쪽의 다른 부위**다. 한 번의 시술로 이렇게 나뉘어 나타나기 어렵다 |
| **시간 간격** | 시술 후 약 4개월. 주사 시술의 급성 합병증은 수일~수주 내 발현한다 |
| **중간 시술** | 사이에 다른 시술이 있어 인과를 하나로 특정할 수 없다 (**환자 설명에는 쓰지 않는다**) |

### 설명 논리

1. 리투오의 기전 재설명 — 보충하는 시술이지 줄이는 시술이 아니다
2. **1회 시술로 연부조직 처짐까지 개선·예방할 수는 없다** — 스킨부스터의 작용 범위와 탄력 저하는 별개
3. 현재 소견은 탄력 저하에 의한 것으로 판단 → **지속적인 리프팅 관리**가 필요하다
4. 얼굴은 원래 좌우가 다르고, **시술 후에는 거울을 더 자주 보게 되어** 전에는 지나쳤던 차이가 눈에 들어오는 경우가 많다

### 제안

팔자주름 부위에 **연어주사 + 물광주사**로 개선 보조. 추가 볼류마이징이 아닌 **보수적 선택**이다.

**한계를 함께 설명하고 기록했다** — 일시적 개선이며 시간 경과에 따라 탄력은 다시 저하된다는 점, 환자가 이해했음을 확인.

## 4. 재사용 가능한 논리 — 스킨부스터 CP 일반

스킨부스터 관련 불만은 대체로 **"기대한 것과 다르다"**이지 진짜 부작용이 아니다. 아래 두 축으로 설명한다.

- **기전 축** — 이 시술이 무엇을 하는 시술인가. 채우는가 줄이는가
- **범위 축** — 이 시술이 어디까지 개선하는가. 탄력·처짐은 스킨부스터의 영역이 아니다

**상담 단계에서 범위를 미리 말하면 CP가 줄어든다.** 시술 후에 한계를 처음 들으면 변명으로 들린다 → [[데스크_응대기준]] · [[시술_추천_프레임워크]]
