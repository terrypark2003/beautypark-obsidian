# 화상 대응 프로토콜 (에너지 기반 시술)

> ⚠️ **draft — 원장 검수 전.** 2026-09-19 부원장 문의에 대한 대표원장 회신을 그대로 옮긴 것이다.
> 인모드 포마·슈링크·레이저 공통으로 쓴다. 확정 시 [[진료_프로토콜]]에 편입한다.

## 1. 즉시 처치 (원내 기준)

1. **즉시 중단**하고 잔여 젤을 닦아낸다
2. **보송크림 도포 → 크라이오 관리로 연결**
3. 즉시 하지 못했더라도 **1시간 이내면 효과가 있다**
4. **사진 촬영** — 경계·범위가 들어가게
5. **수포** — 작은 것은 그대로 둔다. 크거나 터질 것 같으면 무균 배액하되 **상피 덮개는 남긴다**
6. **습윤 드레싱**(폼/하이드로콜로이드) 덮고 귀가

> 3번의 "1시간"은 문헌 근거가 있다(§5). 즉시 못 했다고 포기하지 않는다.

## 2. 이후 관리

| 항목 | 처치 |
|---|---|
| 통증 | 경구 진통소염제 |
| 감염 | 국소 항생제 — **원내 쁘띠 항생제 처방** |
| 홍반 지속 | 국소 스테로이드 **단기** |
| 색소 | **자외선 차단 철저** |

## 3. 진짜 문제는 화상이 아니라 PIH

원내 환자군(피부형 **II~IV**)에서 화상 자체는 1~2주면 아물지만 **색소침착은 몇 달 간다.**
**상피화가 끝나는 시점까지 자외선 차단을 계속 강조**한다.

## 4. 장비별 발생 경로

### 인모드 포마 (양극성 RF)

- 젤이 마르거나 부족할 때
- **한 자리 정체** — 포마는 계속 움직여야 한다
- 전극 부분 접촉 — 가장자리에 에너지가 몰린다
- **마취크림이 남아 환자가 뜨거움을 못 느끼는 경우 ← 실제로 가장 흔하다**

### 슈링크 (HIFU)

결이 다르다. **뼈 돌출부(하악연·관골궁)**와 **중첩 조사**에서 주로 난다.

> 포마는 **접촉·이동**의 문제고, 슈링크는 **해부학적 위치·중첩**의 문제다. 예방 포인트가 서로 다르므로 교육할 때 묶지 않는다.

## 5. 냉각의 문헌 근거

| 내용 | 출처 | 비고 |
|---|---|---|
| **15℃ 흐르는 물 20분**이 최적. 2℃도 유효하나 **얼음은 쓰지 말 것** (재상피화·반흔 조직학·외관 모두 열등) | Wound Repair Regen 2008, **PMID 19128257** | ⚠️ 돼지 모델 |
| **60분까지 지연 냉각해도** 즉시 냉각과 화상 깊이에 유의차 없음 | J Burn Care Res 2009, **PMID 19506512** | ⚠️ 돼지 모델 |

둘 다 동물 모델이며 사람 RCT가 아니다.

## 6. 기록 (4항목 필수)

화상 발생 시 차트에 반드시 남긴다.

1. **즉시 사진**
2. **사용 파라미터**
3. **환자에게 설명한 내용**
4. **다음 경과 관찰 일정**

→ 기록 방식은 [[CP_대응_시술후_불만]] §의무기록 구조를 따른다(환자 진술 / 의학적 판단 / 설명 내용 분리).

## 7. ⚠️ 미확정 — 원장 확인 필요

| 항목 | 내용 |
|---|---|
| **크라이오 적용 시간** | 전달본에 시간 기준이 없다. 문헌 근거는 "20분"인데 크라이오(냉풍)는 매체가 달라 그대로 적용할 수 없다. **몇 분을 기준으로 할지 확정 필요** |
| 보송크림 | 제품·성분과 크라이오 전/후 도포 순서 확정 필요 |
| 쁘띠 항생제 | 품목명과 상시 처방 여부(감염 징후 시에만인지) 확정 필요 |
| 전원 기준 | 전달본에서 제외됐다. 심재성 2도 이상·감염 징후·기저질환 시 외부 의뢰 기준을 둘지 판단 필요 |
| PIH 개입 시점 | 전달본은 자외선 차단까지만 다룬다. 상피화 후 미백 개입 여부·시점 미확정 |
| 수포 처치 · 국소 스테로이드 | 아직 출처를 붙이지 않았다 |

## 8. 전달 문안에서 배운 것

원안에서 대표원장이 고친 지점이 셋이다. → [[문안_작성_원칙]]

| 고친 것 | 이유 |
|---|---|
| "15℃ 흐르는 물 20분" → "보송크림 + 크라이오" | **일반론을 원내에 실제로 있는 자원으로 바꿨다.** 세면대로 뛰어가라는 지시는 진료실에서 실행되지 않는다 |
| "감염 징후 있을 때만 / SSD는 1차 아님" → "쁘띠 항생제 처방" | 판단을 요구하는 문장을 **원내 표준 처방 이름**으로 바꿨다 |
| "분쟁이 생기면 이 기록이 전부입니다" → 삭제, "감사합니다"로 닫음 | 동료에게 보내는 글에서 **위협적 동기 부여를 뺐다.** 기록하라는 요청은 그대로 남기되 이유를 겁으로 대지 않는다 |
