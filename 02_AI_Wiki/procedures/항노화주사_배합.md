# 항노화·영양 주사 — 성분·배합·선택 기준

> **판정: ⚠️ 조건부.** 국내 제품 첨부문서에는 **다른 주사제와의 배합 가능·금기 기재가 없다.** 아래 배합 판단은 각 성분의 **pH 조건과 반응 기전**에 근거한 것이며 정량적 배합 안정성 시험 데이터가 아니다.
> **최종 파라미터는 원장이 결정한다.**

## 1. 원내 주사제 대조표

| 통칭 | 실제 성분 | 식약처 허가 효능효과 | 투여 경로 |
|---|---|---|---|
| 백옥주사 | 글루타치온 | 약물중독·만성간질환 등 | 정맥 (소량씩) |
| 신데렐라주사 | **티옥트산 = 알파리포산** (동일 물질) | **당뇨병성 다발신경병증** | 정맥 (천천히) |
| 마늘주사 | 푸르설티아민 (TTFD) | 비타민 B1 결핍 | 정맥 |
| 감초주사 | 글리시리진산암모늄 + 글리신 + L-시스테인 | 만성간질환 등 | **정맥주사(샷)** — §7-1 |
| 비타민C 주사 | 아스코르브산 | 비타민C 결핍 | 정맥 (천천히) |
| **브이트리** | **나이아신(니코틴산) 50mg/1mL** | **펠라그라·B3 결핍** | 근육 또는 정맥 |
| **아르믹스** | **종합 아미노산 250mL** (L-아르기닌 0.81g + 14종) | **저단백혈증 · 저영양상태 · 「수술 전후의 아미노산 보급」** | **점적주사** |

> ⚠️ **치옥트산과 알파리포산은 같은 물질이다.** 이름만 둘이다(IUPAC: 5-[(3R)-dithiolan-3-yl]pentanoic acid). 둘을 서로 다른 주사로 나눌 수 없다.
> 마늘주사는 **푸르설티아민**(알리티아민 계열 B1 유도체)으로 별개 물질이다. 둘 다 황을 포함해 혼동하기 쉬우므로 **앰플 라벨로 확인**한다.

## 2. 🔑 제품은 카테고리가 아니라 허가 적응증으로 찾는다

2026-09 **수술 후 회복 목적 문의**에서 나온 교훈이다.

"항노화 주사"라는 원내 카테고리 안에서만 후보를 보면 **카테고리 밖의 정답을 놓친다.** 위 표에서 허가사항에 **「수술 전후」**가 적힌 제품은 **아르믹스 하나**다. 나머지는 전부 허가 외 사용이 된다.

```
환자 상황을 먼저 문장으로 쓴다   → "수술 후 회복기"
그 문장이 허가 효능효과에 있는 제품을 찾는다  → 아르믹스
없으면 그때 기전으로 내려간다
```

**허가 적응증이 있는 제품이 있으면 그것이 1순위다.** 허가 외 사용 문제가 없고, 설명·동의도 단순해진다.

## 3. 배합 판정

| 조합 | 판정 | 이유 |
|---|---|---|
| **신데렐라 + 마늘** | ❌ **가장 나쁨** | 티옥트산 주사액은 알칼리(pH 7.6~8.8) · 티아민은 알칼리에서 분해 가속 → §4-1 |
| **백옥 + 마늘** | ❌ | 글루타치온이 푸르설티아민의 이황화를 환원 → 백 안에서 프로드럭 조기 활성화 → §4-2 |
| **비타민C + 마늘** | ❌ | 아스코르브산도 환원제 → 위와 같은 기전 → §4-4 |
| NS 100 + 마늘 + 백옥 | ❌ | 위와 동일 |
| **백옥 + 신데렐라** | ⭕ 넷 중 가장 무난 | 서로 상쇄 방향이 아님. 단 §7 조건 준수 → §4-3 |

**결론 한 줄 — 마늘주사는 단독으로 간다.** 환원제(글루타치온·아스코르브산)와 알칼리(티옥트산) 양쪽 모두와 충돌한다.

**감초주사와 아르믹스는 배합 논의 대상이 아니다.** 감초는 단독 샷(§7-1), 아르믹스는 아미노산 수액으로 다른 주사제를 섞지 않는다.

## 4. 근거

### 4-1. 신데렐라 + 마늘이 가장 나쁜 이유

티옥트산은 약산이라 염 형태로 제제화한다. **트로메타몰염 수용액의 pH는 7.6~8.8**, 시판 주입액 실측 pH는 **6.64~8.35**로 보고된다. [EP0318891, US20040266858A1]

**티아민은 열·빛·알칼리·아황산염에 분해된다.** pH 3보다 pH 6에서 이미 분해 속도상수가 커지고 알칼리에서 더 가속된다. [BMC Chemistry 2021]

→ 알칼리 용액에 티아민을 넣는 것은 약학의 오래된 배합 금기 패턴이다. 한 백에 넣으면 **마늘 성분의 역가가 떨어진다.**

### 4-2. 백옥 + 마늘이 문제인 이유

푸르설티아민(TTFD)은 티아민에 이황화 결합을 붙여 지용성을 높인 **프로드럭**이다. 체내에서 티올이 이 결합을 끊어 티아민을 방출한다.

그 티올이 **글루타치온**이다. Folda 등은 **글루타치온 계와 티오레독신 계가 티아민 이황화 유도체를 환원한다**고 보고했다. [*BioFactors* 2025, **PMID 39302148**]

→ 몸에서 일어나야 할 활성화가 **주사백 안에서 먼저** 일어난다. 지용성 프로드럭을 쓰는 이점이 사라진다.

### 4-3. 백옥 + 신데렐라가 무난한 이유

환원형 티옥트산(DHLA)은 **글루타치온·비타민C·비타민E를 재생시키는 방향**으로 서술된다. 서로 깎아먹는 관계가 아니라 항산화 네트워크를 이룬다. [Linus Pauling Institute]

다만 **관행과 배합 안정성 입증은 다르다.**

### 4-4. 비타민C + 마늘 (2026-09-22 추가)

아스코르브산은 **환원제**로 이황화 결합을 환원할 수 있다. §4-2의 글루타치온 논리가 그대로 적용된다.

→ **같은 백에 넣지 않는다.** 순차 투여, 사이에 생리식염수 플러싱.

## 5. NAD 축 — 브이트리(나이아신)

### 5-1. 실제로 NAD 전구체가 맞다

니코틴산은 **Preiss-Handler 경로**(NA → NaMN → NaAD → NAD⁺)로 NAD⁺가 된다. 니코틴아미드·NR·NMN이 쓰는 salvage 경로와 입구만 다르고 종착점은 같다.

> 미토콘드리아 근병증 환자에게 나이아신 투여 시 **혈중 NAD⁺ 최대 8배 증가**, 근육 NAD⁺ 대조군 수준 회복, 근력·미토콘드리아 생합성 증가.
> *Cell Metab* 2020, **PMID 32386566** — 단, **750~1,000mg/일 경구 4~10개월**

### 5-2. ⚠️ 용량이 근거 구간의 1/15~1/20이다

브이트리주는 **50mg 주사**다. 위 근거는 750~1,000mg 경구 장기 투여에서 나왔다. **50mg 단회 주사가 NAD⁺를 유의하게 올린다는 인체 데이터는 없다.**

### 5-3. 미국의 "NAD 주사"와 다르다

미국 클리닉의 NAD IV는 **NAD⁺ 본체**를 2~4시간 점적하는 것이고, **FDA 승인 의약품이 아니다.** 2026년 리뷰는 **"정맥 NAD⁺ 투여는 특성 규명이 덜 됐고 견고한 임상적 검증이 없다"**고 적는다. [*Mol Biol Rep* 2026, **PMID 42489969**]

→ **"NAD 주사"라는 명칭 자체가 사실과 다르다.** 브이트리는 나이아신이다. → [[의료광고법_가이드]] §56②8

### 5-4. 홍조는 반드시 안내한다

니코틴산은 GPR109A를 통해 프로스타글란딘 D2를 방출시켜 **얼굴·상체 홍조**를 일으킨다. 정맥 투여에서 더 빠르고 뚜렷하다.

**사전 안내가 없으면 이상반응으로 오인되고, 안내해도 "효과"로 오인된다.** 어느 쪽이든 설명이 필요하다.

## 6. ALA(신데렐라)의 수술 후 근거 — 축을 혼동하지 않는다

"수술 후 회복에 좋다"는 말이 돌지만, 실제 근거는 **신경 회복** 쪽이다.

| 연구 | 내용 | 수준 |
|---|---|---|
| *J Med Food* 2018, **PMID 29356576** | 수근관증후군 수술 전후 ALA **600mg/일 경구**(수술 1개월 전~2개월 후). 임상·신경전도 개선 | RCT ⚠️ n=20 |
| *J Hand Surg Asian Pac* 2026, **PMID 41508613** | 후향 n=164. 유의하나 **"임상적으로 경미"**. **수술 전부터 복용한 군만** MCID 초과 | Level III |
| *Arch Gynecol Obstet* 2020, **PMID 30564928** | 제왕절개 후 자궁 창상 치유 RCT | ⚠️ **2024년 Editorial Expression of Concern (PMID 38530442) — 근거로 쓸 수 없음** |

**세 가지 조건이 붙는다.**

1. **경구** 600mg/일 (주사 아님)
2. **수 주~수 개월** (단회 아님)
3. **수술 전부터** 시작

→ 수근관 수술은 **신경 감압술**이다. ALA의 신경보호 작용이 거기서 작동한 것이고, 당뇨병성 신경병증 허가 적응증과 같은 축이다. **창상 치유 축이 아니다.**

→ 수술 부위에 **신경 증상(저림·통증·감각 이상)**이 있으면 경구 ALA를 검토할 수 있다. 없으면 해당 축이 아니다.

## 7. 첨부문서에 명시된 금기·용법

### 7-1. 감초주사는 단독 정맥주사(샷)다

| 구분 | 용법 |
|---|---|
| 일반 | 성인 1일 1회 **2~20mL 정맥주사** |
| 만성간질환 | 1회 40~60mL, 정맥 또는 점적정맥주사 |
| 상한 | 1일 100mL |

> **정맥주사 시 혈관통을 일으킬 수 있으므로 가능한 한 투여속도를 천천히 한다.**

미용 목적 용량(20mL 안팎)은 전부 일반 구간이라 **샷이 허가 용법**이다. 백에 섞을 일이 없으므로 배합 논의에서 제외된다.

### 7-2. 성분별 금기

| 성분 | 기재 내용 |
|---|---|
| 티옥트산 | 금속화합물(철·마그네슘·**칼슘 함유 우유 등**)과 **불용성 착체 형성** → 동시 투여 금지 |
| 티옥트산 | 정맥주사 시 **가능한 천천히** / 포도당 이용률 증가로 **저혈당 유사증상** 가능 |
| 글루타치온 | **아나필락시스 유사반응·과민반응** 보고. 정맥주사 시 소량씩 |
| 아스코르브산 | **G6PD 결핍환자 투여 금지** — 고용량 시 용혈 |
| 아스코르브산 | 아스피린·니코틴·알코올·**철분제**·페니토인·경구피임약·테트라사이클린계 병용 시 조직 탈포화 → 병용 회피 |
| 아스코르브산 | **차광밀봉, 2~8℃ 보관.** 정맥투여 천천히(실신·어지러움·혈관통). 과량 시 고수산뇨증 |
| **글리시리진(감초)** | **감초 함유 제제와 병용 시 글리시리진 중복** → 가성알도스테론증·고도 저칼륨혈증 |
| **나이아신(브이트리)** | 홍조(§5-4) |
| **아르믹스** | 아미노산 부하 — **신기능·간기능 확인.** 용법은 총 아미노산 **체중 kg당 1일 1~1.5g** |

## 8. 원내 실무 프로토콜 (권고)

1. **희석액은 NS만.** 티옥트산이 들어가면 칼슘·마그네슘 함유 수액(하트만액·링거액)은 쓰지 않는다.
2. **마늘주사는 단독**으로 먼저 또는 나중에 투여한다. 환원제(백옥·비타민C)와 알칼리(신데렐라) 양쪽 모두와 충돌한다.
3. 백옥 + 신데렐라는 NS에 함께 가능. **차광하고 조제 후 즉시 투여**(둘 다 광분해·산화에 취약).
4. **감초주사는 단독 샷.** 천천히.
5. **아르믹스는 점적.** 다른 주사제를 섞지 않는다. 시술 일정에 **점적 시간**을 반영한다.
6. 라인 사이는 **생리식염수로 플러싱**한다.
7. 배합 데이터가 없는 조합을 임의로 한 백에 섞지 않는다. **순차 투여가 원칙** — 이상반응 시 원인 약제를 특정할 수 있다.
8. 고용량 비타민C 예정이면 **G6PD 결핍 여부를 문진**한다. 신결석 병력자는 수분 섭취 안내.
9. **브이트리 전 홍조를 안내**한다.

## 9. 미확인·후속

- [ ] **원내 사용 제품의 실제 pH** — 티옥트산 제품별 염 형태가 다르므로 제조사 문의로 확정
- [ ] 원내 사용 제품명·제조사 전체 목록 → 제품별 첨부문서 대조
- [ ] 푸르설티아민 첨부문서의 배합 관련 기재
- [ ] 아르믹스 250mL의 **총 아미노산 함량** — 체중 기준 용량 계산에 필요
- [ ] 혼합 후 시간 경과별 역가 저하 정량 데이터 — 공개 자료 없음
- [ ] 원장 검수 후 `verified` 상신

## 10. 이 문서의 한계

국내 제품 첨부문서에는 **다른 주사제와의 혼합·배합에 관한 기재 자체가 없다.** 따라서 §3 판정은 성분의 pH 조건과 반응 기전에서 도출한 것이며, "배합 안정성이 입증되었다/부정되었다"는 뜻이 아니다. **첨부문서에 없는 혼합은 허가사항 외 사용이다.**
